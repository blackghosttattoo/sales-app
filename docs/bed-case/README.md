# 베드 센서 케이스 v1 (2026-10-13)

ESP32 DevKitC 38핀(USB-C) + LD2410C 레이더를 한 통에. **천장·조명 레일에 붙이고 레이더가 아래(베드)를 봄.** 점퍼선 꽂기 방식.

- 파일: `bed-case.3mf`(뱀부 스튜디오에서 바로 열기, 몸통+뚜껑), `body.stl`, `lid.stl`, 설계 `make_case.py`(숫자 바꿔 다시 만들기)
- 바깥 크기: 약 33 × 76 × 34mm (몸통 31.6 + 뚜껑 판 2)
- 부품 치수는 사진·규격으로 추정: ESP32 28.5×52mm, LD2410C 22×16mm, 핀 헤더 플라스틱 2.5mm. 실제와 다르면 `make_case.py` 맨 위 숫자만 고치면 됨.

## 구조
- **바닥 = 레이더가 보는 면**(두께 1.6mm, 레이더 밑은 1.2mm). 바닥에 레이더 자리(살짝 파인 홈 + 낮은 테두리) — 부품 면(칩 보이는 면)이 위, 매끈한 안테나 면이 바닥을 보게.
- **ESP32**: 핀이 아래로 가게(칩이 위). 안테나 쪽 30mm는 양쪽 벽 레일의 홈에 핀 줄이 쏙 들어가고 검은 플라스틱이 레일 위에 얹힘. USB 쪽은 모서리 받침 턱 2개. 보드 밑 약 2cm 공간에 점퍼선 꽂기·남은 선 말아 넣기.
- **USB-C 구멍**: 위가 열린 U자 — 케이블 먼저 꽂고 뚜껑 덮음.
- **뚜껑 = 천장에 붙는 면**: 끼움 턱 + 딸깍 돌기 4개, 안쪽 기둥이 ESP32 은색 모듈을 살짝 눌러 들뜨지 않게. 나사 구멍 2개(접시머리 3mm 나사) — 양면테이프만 써도 됨.
- 긴 벽에 통풍구. EN·BOOT 버튼은 막혀 있음(프로그램은 처음 한 번 넣고 이후 와이파이로 업데이트하니까).

## 출력 (뱀부랩 P2S)
- 필라멘트: **PLA 또는 PETG만**(메탈·실크·카본 = 레이더 막힘 ✗)
- 몸통: 바닥이 판에 닿게 그대로 / 뚜껑: 넓은 면이 판에 닿게(3mf에 이미 그렇게 놓여 있음)
- 0.2mm 레이어, 벽 3겹, 채움 15%, **서포트 없음**

## 조립
1. 점퍼선 3가닥: 레이더 **VCC → ESP32 5V**, **GND → GND**, **OUT → GPIO13**(5V 핀 줄의 USB 쪽 근처)
2. 레이더를 바닥 자리에 놓기(안테나 면이 바닥, 필요하면 양면테이프 작은 조각)
3. ESP32를 핀이 아래로, USB가 U자 구멍 쪽으로 가게 레일 홈에 눌러 넣기
4. 남은 선은 보드 밑에 말아 넣고, USB 케이블 꽂고, 뚜껑 딸깍

## 맞춰 볼 것 (처음 출력 후 알려 주기)
- 보드가 레일 홈에 너무 빡빡/헐렁한지, 레이더 자리 크기, 뚜껑 끼움 세기, USB 케이블 머리가 구멍에 들어가는지
