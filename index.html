⏳ 계속 이 화면에서 멈춰 있나요?
🍎 아이폰
  1. 카카오톡·인스타그램 안에서 열었다면 → 아래(또는 위) ⋯ 버튼 → 'Safari로 열기'
  2. Safari에서도 멈추면 → 설정 → Safari → 방문 기록 및 웹사이트 데이터 지우기, 콘텐츠 차단기(광고 차단) 끄기, 비공개 모드 끄기
  3. iOS 14 이상이어야 해요 (설정 → 일반 → 정보)
  4. 열리면 Safari 공유 □↑ → '홈 화면에 추가'
🤖 갤럭시 (안드로이드)
  1. 카카오톡·인스타그램 안에서 열었다면 → 오른쪽 위(또는 아래) ⋮ 버튼 → '다른 브라우저로 열기' → 크롬(Chrome)
  2. 크롬에서도 멈추면 → 크롬 ⋮ → 설정 → 개인정보 보호 → 인터넷 사용 기록 삭제(쿠키·캐시) 후 다시 열기. 삼성 인터넷은 광고 차단 끄기, 안 되면 크롬으로
  3. 열리면 크롬 ⋮ → '홈 화면에 추가'(또는 '앱 설치')
