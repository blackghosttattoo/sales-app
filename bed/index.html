👻 베드 센서 설치 — 처음부터

BLACKGHOST TATTOO STUDIO · 보드 1개당 한 번. 순서대로만 하면 돼요. (프로그램 v5)

0준비물

  • ESP32 보드(NodeMCU-32S) + 레이더(LD2410C) + 점퍼선 3가닥
  • 윈도우 컴퓨터(크롬) + 데이터용 USB-C 케이블 (처음 한 번만 컴퓨터 필요)
  • 폰 (와이파이 설정용)
  • 보드 비밀번호 하나 정하기: 8자 이상, 따옴표 " 와 \ 빼기. 4개 보드 모두 같은 것. 채팅에 보내지 말고 따로 적어 두기.

1컴퓨터 준비 (처음 한 번)

  1. CP210x 드라이버 → CP210x Windows Drivers 받기 → 압축 풀기 → CP210xVCPInstaller_x64.exe 실행 → 다음·마침.
  2. 프로그램 파일 받기: ⬇ bed.bin 받기
    다운로드 폴더에 "bed"로 보이면 맞아요(약 1.2MB). 예전 것이 있으면 지우고 새로 받기.

2보드에 프로그램 넣기 (레이더 선 모두 빼고!)

  1. 레이더 선을 보드에서 모두 뺀 상태로 USB를 컴퓨터 본체 뒤쪽에 꽂기.
  2. ESP Tool 열기 (다른 ESP 탭은 모두 닫기).
  3. 받기 모드: 보드의 IO0(USB 오른쪽 버튼)를 누른 채 → EN(왼쪽 버튼)을 눌렀다 떼고 → IO0 떼기.
  4. Baudrate 115200 → Connect → CP210x 선택 → 연결. 검은 창에 Chip is ESP32가 나오면 성공.
  5. (처음 쓰는 보드거나 문제가 있었던 보드만) 빨간 Erase Flash → 끝날 때까지 기다리기.
  6. Flash Address 0x0 + 파일 선택에서 bed → Program → 약 1분 → Hash of data verified가 나오면 끝.
  7. Disconnect → 보드의 EN 한 번.

오류 'Failed to open' = 다른 탭 닫고 USB 뺐다 꽂기 · 'Failed to connect' = 3번(받기 모드) 다시 · 중간에 끊김 = 레이더 선 빠졌는지 확인하고 다시

3폰으로 와이파이 설정 (USB 꽂아 둔 채, 레이더 선은 아직 빼 둔 채)

  1. 보드 파란 불이 계속 켜져 있으면 설정 기다리는 중.
  2. 폰 와이파이에서 BG-BED-SETUP 연결 ("인터넷 없음" → 연결 유지).
  3. 크롬/삼성 인터넷 주소창에 192.168.4.1 (안 열리면 모바일 데이터 잠깐 끄기).
  4. Configure WiFi → 가게 와이파이(2.4GHz, _5G 아닌 것) 누르기 → 칸 채우기:
    Password가게 와이파이 비밀번호
    베드 번호1 ~ 4
    보드 비밀번호0번에서 정한 것
  5. Save → BG-BED-SETUP이 목록에서 사라지면 성공 (파란 불 꺼짐).

4레이더 연결 (USB 빼고!)

3가닥만 꽂아요. TX·RX는 안 써요.

레이더보드 (뒷면 글씨, USB 쪽 줄)
VCC5V (USB 쪽 맨 끝)
GNDGND (5V 바로 다음)
OUTP13 (GND 다음 SD3·SD2를 건너뛰고 그다음)

⚠ SD3 · SD2 · P12 · 3V3 에는 절대 꽂지 않기 (보드가 안 켜져요)

꽂은 뒤 USB를 다시 꽂기 (이제부터는 폰 충전기에 꽂아 둬도 돼요).

5확인

파란 불뜻
켜질 때 3번 깜빡프로그램 시작
계속 켜짐 (BG-BED-SETUP 보임)와이파이 설정 기다림 → 3번 다시
빠르게 깜빡깜빡와이파이 연결 중/끊김 (가게 와이파이 확인)
2초마다 짧게 두 번앱 기록 실패 (보드 비밀번호 확인 → IO0 5초로 다시 설정)
사람 있으면 켜짐 · 없으면 10초쯤 뒤 꺼짐정상 ✅ 앱 '🛏 베드 현황'에 표시

설정을 다시 하려면 보드의 IO0 버튼 5초 → BG-BED-SETUP이 다시 생겨요. 프로그램이 새로 나오면 보드가 와이파이로 스스로 업데이트해요.

감지 거리를 1.5m로 줄이기(옆 베드 안 잡히게)는 레이더를 단 뒤 폰 앱 HLKRadarTool(블루투스)로 해요 — 나중에 같이.
