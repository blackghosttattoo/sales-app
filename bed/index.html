👻 베드 센서 설치 (1단계 시험)

BLACKGHOST TATTOO STUDIO · 보드에 프로그램 넣기. 처음 한 번만 하면 돼요.

① 선 연결 (USB 빼고)

레이더보드
VCC5V
GNDGND
OUTP13

TX·RX는 안 써요. 3V3 말고 꼭 5V.

② 컴퓨터에 USB로 연결

  1. 크롬이나 엣지로 이 페이지를 열어요 (폰·사파리는 안 돼요).
  2. 데이터용 USB-C 케이블로 보드를 컴퓨터에 꽂아요. (충전 전용 케이블은 안 잡혀요)

③ 설치 버튼 누르기

이 브라우저는 안 돼요. 컴퓨터의 크롬이나 엣지로 열어 주세요. https 주소로 열어 주세요.
  1. 창이 뜨면 목록에서 CP2102 또는 USB to UART 같은 이름을 골라 [연결].
  2. [INSTALL / 설치] → 지우고 설치 확인 → 1~2분 기다리기.
  3. 목록에 아무것도 안 뜨면: 케이블을 바꿔 보거나, 윈도우라면 CP210x 드라이버를 설치해요.
  4. 'Preparing installation'에서 멈추면(이 보드는 자주 그래요): 창 닫기 → 레이더 선 빼기 → 보드의 IO0 버튼을 누른 채 EN 버튼을 눌렀다 떼고 IO0도 떼기 → 다시 설치.
  5. 그래도 안 되면 에스프레시프 공식 설치 페이지: Baudrate 115200 → Connect → 주소 0x0, 파일 bedtest.bin → Program (대장님 첫 설치는 이 방법으로 성공).
  6. 'Failed to open serial port'가 나오면 이 보드를 쓰는 다른 탭을 닫고 USB를 뺐다 꽂기.
  7. 설치가 끝나면 EN 버튼을 한 번 눌러 다시 켜기.

④ 시험해 보기

  1. 설치가 끝나면 보드의 파란 불이 3번 깜빡여요 = 잘 들어감.
  2. 레이더 앞에서 움직이면 파란 불이 켜지고, 멀리 가거나 방을 나가면 잠시 뒤 꺼져요.
  3. 컴퓨터 없이 폰 충전기에 꽂아도 똑같이 동작해요.

지금은 레이더 기본 설정이라 꽤 멀리(최대 약 6m)까지 감지해요. 1.5m로 줄이는 건 2단계(와이파이 연결)에서 같이 해요.
