👻 베드 센서 설치

BLACKGHOST TATTOO STUDIO · 보드에 프로그램 넣기. 처음 한 번만 하면 돼요.

⭐ 2단계: 와이파이 버전 (앱에 베드 현황)

  1. 보드 비밀번호 정하기: 8자 이상(따옴표 " 와 \\ 는 빼기)으로 하나 정해서 적어 두세요. Firebase 콘솔에서 따로 만들 필요 없어요 — 첫 보드가 설정할 때 보드 계정(bed@blackghost.app)을 스스로 만들어요. 4개 보드 모두 같은 비밀번호를 넣어요.
  2. 선 2가닥 추가 (USB 빼고): 레이더 TX → P16, 레이더 RX → P17 (보드 왼쪽 줄). 기존 VCC→5V, GND→GND, OUT→P13은 그대로.
  3. 프로그램 넣기: 레이더 선 5가닥 빼고 → bed.bin 받기 → ESP Tool에서 115200 → (IO0 누른 채 EN 눌렀다 떼고 IO0 떼기) → Connect → 주소 0x0 + bed.bin → Program → 끝나면 Disconnect → 선 다시 꽂고 EN.
  4. 폰으로 와이파이 설정: 보드가 켜지면 파란 불이 계속 켜져 있어요(설정 기다리는 중). 폰 와이파이 목록에서 BG-BED-SETUP 접속 → 설정 화면이 자동으로 뜨면(안 뜨면 주소창에 192.168.4.1) Configure WiFi → 가게 와이파이(2.4GHz) 고르고 비밀번호, 베드 번호(1~4), 보드 비밀번호(1번에서 정한 것), 감지 거리 칸 2(=1.5m) → Save.
  5. 보드가 가게 와이파이에 붙으면 BG-BED-SETUP이 사라지고, 사람 있으면 파란 불이 켜져요. 앱의 🛏 베드 현황에 그 베드가 나타나요(1~2초).
  6. 설정을 다시 하려면: 보드의 IO0 버튼을 5초 누르면 BG-BED-SETUP이 다시 생겨요.
  7. 프로그램이 새로 나오면 보드가 6시간마다 확인해서 와이파이로 스스로 업데이트해요(다시 꽂을 필요 없음).

1단계: 동작 시험 (참고)

① 선 연결 (USB 빼고)

레이더보드
VCC5V
GNDGND
OUTP13

TX·RX는 안 써요. 3V3 말고 꼭 5V.

② 컴퓨터에 USB로 연결

  1. 크롬이나 엣지로 이 페이지를 열어요 (폰·사파리는 안 돼요).
  2. 데이터용 USB-C 케이블로 보드를 컴퓨터에 꽂아요. (충전 전용 케이블은 안 잡혀요)

③ 설치 버튼 누르기

이 브라우저는 안 돼요. 컴퓨터의 크롬이나 엣지로 열어 주세요. https 주소로 열어 주세요.
  1. 창이 뜨면 목록에서 CP2102 또는 USB to UART 같은 이름을 골라 [연결].
  2. [INSTALL / 설치] → 지우고 설치 확인 → 1~2분 기다리기.
  3. 목록에 아무것도 안 뜨면: 케이블을 바꿔 보거나, 윈도우라면 CP210x 드라이버를 설치해요.
  4. 'Preparing installation'에서 멈추면(이 보드는 자주 그래요): 창 닫기 → 레이더 선 빼기 → 보드의 IO0 버튼을 누른 채 EN 버튼을 눌렀다 떼고 IO0도 떼기 → 다시 설치.
  5. 그래도 안 되면 에스프레시프 공식 설치 페이지: Baudrate 115200 → Connect → 주소 0x0, 파일 bedtest.bin → Program (대장님 첫 설치는 이 방법으로 성공).
  6. 'Failed to open serial port'가 나오면 이 보드를 쓰는 다른 탭을 닫고 USB를 뺐다 꽂기.
  7. 설치가 끝나면 EN 버튼을 한 번 눌러 다시 켜기.

④ 시험해 보기

  1. 설치가 끝나면 보드의 파란 불이 3번 깜빡여요 = 잘 들어감.
  2. 레이더 앞에서 움직이면 파란 불이 켜지고, 멀리 가거나 방을 나가면 잠시 뒤 꺼져요.
  3. 컴퓨터 없이 폰 충전기에 꽂아도 똑같이 동작해요.

지금은 레이더 기본 설정이라 꽤 멀리(최대 약 6m)까지 감지해요. 1.5m로 줄이는 건 2단계(와이파이 연결)에서 같이 해요.
