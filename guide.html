준비물

  • 내 이메일 주소 (자주 쓰는 메일. 인증 메일이 와요)
  • 가게 가입코드 (대장님께 따로 받아요. 남에게 알려주지 마세요)
  • 휴대폰 (아이폰은 Safari, 안드로이드는 Chrome을 추천해요)

앱 주소: https://blackghosttattoo.github.io/sales-app/ 하나뿐이에요. 다른 주소에서 비밀번호를 묻는다면 입력하지 마세요.

1카톡에서 열렸다면 브라우저로 다시 열기

카카오톡에서 링크를 누르면 카톡 안의 화면으로 열려요. 여기서는 홈 화면 추가가 안 되고 로그인이 자주 풀려요. 오른쪽 아래(또는 위) ⋮ 메뉴에서 다른 브라우저로 열기(아이폰은 Safari로 열기)를 눌러주세요.

2가입하기 → 인증 메일 확인

  1. 앱에서 이메일과 비밀번호(6자 이상)를 쓰고 [가입하기]를 눌러요.
  2. 메일함에 온 인증 메일의 링크를 눌러요. 안 보이면 스팸함·프로모션함을 확인하세요.
  3. 앱으로 돌아와 새로고침하면 다음 화면이 나와요.

3가입 정보 입력 → 승인 기다리기

  1. 이름, 닉네임(앱에서 이 이름으로 보여요), 가입 구분(타투이스트 / 수강생), 가게 가입코드를 넣고 [신청].
  2. "승인 대기 중"이 보이면 끝! 대장님이 승인하면 바로 쓸 수 있어요. 승인 후 앱을 새로고침하세요.
수강생은 가입 구분에서 수강생을 고르고 기수(예: 12)도 적어주세요.

4홈 화면에 추가 (앱처럼 쓰기)

한 번 추가하면 폰 바탕화면에 블랙고스트타투(전용) 아이콘이 생기고, 앱처럼 바로 열려요. 앱스토어 설치는 필요 없어요.

아이폰

Safari로 열기 → 아래 공유 □↑ 버튼 (안 보이면 주소창 옆 ⋯을 먼저) → 홈 화면에 추가 → 추가

안드로이드

Chrome으로 열기 → 오른쪽 위 ⋮ → 홈 화면에 추가 또는 앱 설치 → 설치/추가. 삼성 인터넷은 ≡ → 현재 페이지 추가 → 홈 화면

사용법 한눈에

화면 아래 메뉴로 이동해요.

🏘 블랙고스트마을 (첫 화면)

노을빛 유령 마을이 첫 화면이에요. 위아래로 밀어 구경하고, 건물을 누르면 들어가요: 🧴 타투크림하우스 = 판매입력, 🤝 토스하우스, 💳 쉐어하우스, 📦 창고 = 비품, 🎁 소원 분수 = 복권·이벤트, 🌱 유령 온실 = 유령 키우기, 🎨 꾸미기 상점, 🎮 게임 동굴, 🏰 대장님 성 = 공지·샵 규칙. 건물 위 말풍선(🔔 승인, 🎟 복권 등)은 할 일 알림. 땅을 누르면 내 유령이 날아가요. 🔇 버튼으로 배경 음악, 🌙로 낮·밤.

📋 내현황

이번 달 예상 판매수당(정산/미정산), 받은 토스·보낸 토스, 내 모든 기록이 시간순으로. 기록을 누르면 상세를 볼 수 있어요.

🧾 판매입력

크림을 팔 때마다 바로 입력! 정상판매 · 리뷰이벤트 · 서비스 · 샘플. 금액은 자동으로 들어가요. 입력된 건만 판매수당이 정산돼요.

🤝 토스

작업을 넘길 때 보내는 사람이 입력해요. 수수료는 작업비의 10~20%. 받는 사람이 승인하면 반영돼요.

💳 쉐어비

비밀번호를 한 번 더 넣어야 열려요(본인만). 매월 15일 결제. 입금했는데 미납으로 보이면 납부확인 요청.

🎁 더보기 → 이벤트

매일 복권은 하루 1장(레벨이 높으면 더)! 그날 밤 12시까지 긁어야 하고, 안 긁으면 소멸돼요. 당첨금은 쉐어비 할인으로 — 16일~다음 달 15일 당첨분이 그다음 달 쉐어비에서 자동으로 빠져요.

👻 유령 키우기

나만의 유령을 키워요! 판매 입력 = 밥, 토스 = 기분, 오늘의 문구 미션·복권 긁기 = 경험치. 알 → 아기 → 어른 → 전설로 자라고 꾸미기도 열려요. 오래 쉬면 시무룩해져요. 🎮 유령 게임(점프·사탕 받기·무덤 숨바꼭질·잉크 찍기)으로 하루 최대 30포인트를 모아 유령을 키우고 꾸미기를 살 수 있어요. 게임 포인트는 레벨·복권·쉐어비와는 상관없어요.

📚 더보기 → 기본교육 · 🗓 컨벤션 일정

바늘·잉크·머신·용품·위생 기본기 정리, 국내외 타투 컨벤션 달력(매달 자동 업데이트)을 볼 수 있어요.

📜 맨 위 두루마리 버튼

문신사법 안내(2027년 10월 29일 시행)를 쉽게 정리했어요. 샵 이용규칙은 준비 중이에요.

📦 더보기 → 비품·소모품

재고·상태를 보고, 필요한 것은 요청하면 대장님이 확인해요.

리뷰이벤트 입력 요령

  1. 리뷰 채널을 먼저 고르세요 (네이버 / 구글). 1인 1구매라 수량은 없어요.
  2. 네이버: 영수증 인증 때문에 카드만. 크림을 따로 결제했다면 크림 별도결제 체크 → 100원 + 현금/이체.
  3. 구글: 현금 · 이체 · 카드 중 선택. 이체는 입금자명을 꼭 적어요.
  4. 리뷰 아이디 · 이름 · 캡처 사진 중 하나는 꼭 남겨주세요.

서비스(무료 제공)

받는 사람 이름과 내용을 적으면 대장님 승인 후 반영돼요. 0원이고 판매수당은 없어요.

자주 묻는 질문

"이메일 주소 형식이 맞지 않아요" 라고 나와요
이메일 칸이 비어 있거나, 앞뒤에 띄어쓰기가 있거나, @가 빠졌을 때 나와요. name@gmail.com 처럼 정확히 입력해 주세요. 키보드가 한글 상태로 입력되지 않았는지도 확인하세요.
복권을 어제 못 긁었어요
매일 복권은 발행된 날 밤 12시까지만 긁을 수 있어요. 지나면 '소멸 (안 긁음)'으로 바뀌고 다시 받을 수 없어요. 매일 앱을 열어 긁어 주세요!
복권 당첨 금액이 사람마다 달라요
당첨 금액은 각자의 쉐어비 금액에 맞춰 정해져요. 그래서 같은 날 당첨돼도 금액이 다를 수 있어요. 당첨되면 받는 금액 그대로 다음 쉐어비에서 빠져요. 그달이 휴무면 다음에 쉐어비를 내는 달로 넘어가요.
쉐어비 금액이 ●●●원으로 가려져 있어요
옆 사람이 보지 못하게 가려 둔 거예요. 금액이나 [👁 누르고 있는 동안 금액 보기]를 꾹 누르고 있는 동안만 보여요. 쉐어비 화면에는 이름·시간·'유출금지'가 흐리게 표시돼요. 캡처해서 다른 사람에게 보내지 마세요.
오류가 났어요. 캡처해서 보내야 하나요?
오류 창의 [대장님께 오류 보내기]를 누르면 오류 내용이 대장님께 바로 전달돼요. 캡처하지 않아도 돼요. (비밀번호·쉐어비 같은 개인 정보는 보내지 않아요)
앱 색깔·배경을 바꾸고 싶어요
더보기 → 화면 테마에서 핑크·핫핑크·블랙앤골드·스카이 등 10가지 색과 배경(무늬·내 사진)을 고를 수 있어요. 내 폰에만 적용돼요.
앱 버전은 어디서 봐요?
더보기 맨 아래에 적혀 있어요 (예: v1.30).
홈 맨 위 문구는 뭐예요?
'오늘의 문구'예요. 인스타·블로그·리뷰 등 홍보에 도움이 되는 한마디가 날마다 바뀌어요. 오른쪽 위 📜 버튼에는 문신사법 안내가 있어요.
인증 메일이 안 와요
스팸함 · 프로모션함을 먼저 확인하세요. 그래도 없으면 이메일 주소에 오타가 없는지 보고, 앱에서 로그인한 뒤 화면 안내대로 다시 시도해 주세요. 회사·학교 메일보다 Gmail · 네이버 메일이 잘 와요.
비밀번호를 잊어버렸어요
앱 첫 화면에서 이메일을 쓰고 [비밀번호 재설정]을 누르면 메일로 새 비밀번호를 정하는 링크가 와요. 대장님도 비밀번호를 볼 수 없으니 직접 바꾸셔야 해요.
"승인 대기 중"에서 안 넘어가요
대장님이 승인해야 사용할 수 있어요. 승인됐다고 들었는데도 그대로면 새로고침하거나 앱을 껐다 켜세요.
홈 화면 추가 메뉴가 안 보여요
카톡 안에서 열린 화면이면 메뉴가 없어요. 다른 브라우저로 열기로 Safari(아이폰) · Chrome(안드로이드)에서 열어 주세요. 아이폰은 Safari에서만 홈 화면 추가가 돼요.
잘못 입력했어요. 지울 수 있나요?
내 판매는 상세 화면에서 [수정]할 수 있어요(수정 기록이 남아요). 날짜를 바꾸거나 취소하려면 대장님께 말씀해 주세요. 정산이 끝난 달의 판매는 대장님만 고칠 수 있어요.
지난 날짜로 입력하고 싶어요
판매는 그날그날 입력하는 게 원칙이라 오늘 날짜로만 들어가요. 빠뜨린 건이 있으면 대장님께 말씀해 주세요. 대장님이 날짜를 정해 대신 입력해 줄 수 있어요.
토스 저장이 안 돼요
손님 이름 · 받는 사람 · 작업비를 다 넣었는지, 수수료가 작업비의 10~20% 안인지, 결제를 나눴다면 합계가 작업비와 같은지 확인해 주세요.
쉐어비 화면이 안 열려요
쉐어비는 개인 정보라 로그인 비밀번호를 한 번 더 넣어야 열려요. 다른 메뉴로 나가면 다시 잠겨요.
쉐어비를 냈는데 미납으로 보여요
그 달 옆의 [납부확인 요청]을 누르고 "몇 월 며칠, 입금자명" 등을 적어 보내세요. 대장님이 확인하면 완료로 바뀌어요.
폰을 바꿨어요 / 다른 폰에서도 쓰고 싶어요
같은 이메일 · 비밀번호로 로그인하면 기록이 그대로 보여요. 모든 기록은 폰이 아니라 서버에 저장돼요.
화면이 예전 그대로예요 (업데이트가 안 돼요)
앱 맨 위에 버전(v숫자)이 보여요. 대장님이 새 버전을 알렸는데 숫자가 그대로면 화면을 아래로 당겨 새로고침하거나 앱을 껐다 켜세요.
뒤로가기를 누르면 앱이 꺼져요
팝업이 열려 있으면 팝업이 먼저 닫히고, 다른 메뉴에서는 홈으로 와요. 홈에서 한 번 더 누르면 앱이 닫혀요.
화면이 너무 어둡거나 밝아요
더보기 → 화면 테마에서 자동 · 밝게 · 어둡게를 고를 수 있어요.
인터넷이 안 될 때도 입력되나요?
잠깐 끊긴 정도는 다시 연결될 때 자동으로 올라가요. 하지만 오래 끊긴 상태에서 입력한 판매는 거절될 수 있어요. 가능하면 인터넷이 될 때 입력하고, 저장 후 목록에 보이는지 확인하세요.

보안 · 개인정보, 걱정 마세요

내 쉐어비와 판매수당은 나와 대장님만 봐요.
화면에서 숨기는 게 아니라, 서버가 처음부터 다른 사람에게 데이터를 보내지 않아요. 앱 주소나 화면 코드가 알려져도 대장님 승인 없이는 아무것도 볼 수 없어요.

이런 것도 지켜져요

📵 폰 권한 요구 없음

연락처 · 위치 · 사진첩 전체 접근을 요구하지 않아요. 리뷰 캡처는 내가 고른 사진 한 장만 올라가요.

🧾 기록 조작 방지

수정하면 누가 · 언제 · 무엇을 바꿨는지 남아요. 금액과 수수료는 서버가 다시 계산해서 검사해요.

🔐 가입 승인제

가게 가입코드 + 이메일 인증 + 대장님 승인. 세 단계를 거쳐야 쓸 수 있어요.

☁️ 안전한 저장

기록은 구글 클라우드(Firebase)에 저장돼요. 폰을 잃어버려도 기록은 사라지지 않아요. 광고 · 방문 추적 기능은 넣지 않았어요.

내가 지켜야 할 3가지

  1. 다른 곳과 다른 비밀번호를 쓰세요. 비밀번호와 가입코드는 아무에게도 알려주지 마세요.
  2. 가게 공용 폰이나 남의 폰에서 썼다면 꼭 로그아웃(앱 맨 위)하세요.
  3. 앱 주소는 blackghosttattoo.github.io/sales-app 하나뿐이에요. 비슷한 주소나 메시지로 비밀번호를 묻는다면 입력하지 말고 대장님께 알려주세요.
